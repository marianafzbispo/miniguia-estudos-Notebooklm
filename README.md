# 🧠 Miniguia de Estudos com NotebookLM – Grace Hopper

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de criar um **"Segundo Cérebro"** utilizando o **NotebookLM**, tendo como base os conhecimentos, a trajetória e a forma de pensar de **Grace Hopper**, uma das maiores pioneiras da Ciência da Computação.

A proposta consiste em centralizar conteúdos de diferentes fontes, transformando-os em um material de estudo estruturado, permitindo compreender não apenas a história de Grace Hopper, mas também sua visão sobre programação, inovação, resolução de problemas e evolução da tecnologia.

Além da organização do conhecimento, o projeto demonstra como utilizar técnicas de **Engenharia de Prompts** para extrair informações relevantes de uma IA baseada em documentos, criando um guia reutilizável para estudos futuros.

---

# 🎯 Objetivos

* Criar um ambiente de estudos utilizando o NotebookLM.
* Consolidar conhecimentos sobre Grace Hopper e sua contribuição para a computação.
* Desenvolver um "Segundo Cérebro" capaz de responder perguntas com base em fontes confiáveis.
* Praticar Engenharia de Prompts para obter respostas mais precisas da IA.
* Produzir um material organizado para futuras consultas e revisões.

# 💡 Engenharia de Prompts

Durante o desenvolvimento foram realizados diversos testes para explorar a capacidade do NotebookLM.

### Exemplos de prompts utilizados

* Quem foi Grace Hopper e por que ela é considerada uma das maiores pioneiras da computação?
* Explique como Grace Hopper enxergava o futuro da programação.
* Quais foram suas maiores contribuições para o desenvolvimento das linguagens de programação?
* Como seus ensinamentos podem ser aplicados pelos desenvolvedores atualmente?
* Resuma sua trajetória em linguagem simples.
* Crie um glossário dos principais conceitos relacionados à sua carreira.
* Quais princípios de inovação podem ser aprendidos com Grace Hopper?

### Dificuldades encontradas

* Necessidade de reformular perguntas para obter respostas mais objetivas.
* Diferenças entre respostas quando os prompts eram muito amplos ou muito específicos.
* Necessidade de validar as respostas com as fontes utilizadas.
